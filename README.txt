选型页（静态版）
================

这一整个目录就是网站，不需要任何服务器程序。
计算在打开页面的人的浏览器里完成，产品数据就在 data.json 里。

两个页面
--------
index.html    旋转平台选型（MTN / ZTT / XZT / XZTF）
gearbox.html  减速机选型（齿轮副 / 链带 → 行星减速机）

怎么用
------
1) 本机试：在该目录下开一个静态服务器再打开（直接双击 index.html 不行，
   浏览器会拦住 module 脚本）：
       npx serve .            （或者：python -m http.server 8080）
   然后打开 http://localhost:8080/

2) 发给同事：整个目录上传到静态托管即可，例如
   · 腾讯云 CloudBase 静态网站托管（有免费额度，实名即可，默认域名国内可直连）
   · 任意内网 nginx / IIS / Apache 的静态目录
   · 放在共享盘上，用任意静态服务器指过去

注意
----
· 页面里的"打印 / 另存为 PDF"用浏览器打印对话框出 PDF；服务端那两版精美报告
  （客户版 / 内部版）需要 B 方案（云服务器）才有。
· 数据变了要重新构建一次（npm run build:static）再上传，同事刷新页面就是新数据。
· ?debug=1 仍是内部视图（余量、校核、候选表）。
